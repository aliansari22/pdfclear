# PDFClear roadmap

This roadmap is a public planning document, not a promise of delivery dates. Contributions and focused proposals are welcome.

## Near term

- Add Playwright smoke tests for the most-used PDF workflows.
- Measure and reduce initial JavaScript and WebAssembly download size.
- Improve keyboard navigation, focus management, and screen-reader labels.
- Document fully self-hosted OCR and AI model deployments.
- Add a repeatable privacy and network-request audit.
- Expand browser compatibility testing and publish a support matrix.
- Improve error messages for large documents and memory-constrained devices.

## Contributor-friendly work

- Add screenshots or short recordings to tool documentation.
- Improve mobile layouts for page reordering and visual editing.
- Expand OCR language documentation.
- Add translations for navigation and common workflow messages.
- Add unit tests for page-range parsing and file-size formatting.
- Review metadata, headings, and structured data for accessibility and SEO.

## Longer-term ideas

- Optional desktop packaging for fully offline workflows.
- User-configurable self-hosted model registries.
- More advanced annotation and redaction workflows.
- Batch workflow presets that remain local to the browser.
- Signed release artifacts and software-bill-of-materials generation.

Please discuss substantial features before implementing them so the scope, privacy impact, and browser performance tradeoffs can be reviewed early.
