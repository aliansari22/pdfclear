# Support

For general questions, setup help, and self-hosting discussion, use GitHub Discussions after the repository is published.

For bugs, open an issue and include the browser, operating system, deployment type, console output when relevant, and clear reproduction steps. Do not upload private or sensitive PDFs when filing public issues.

For suspected security vulnerabilities, do not open a public issue. Follow the private reporting guidance in [`SECURITY.md`](SECURITY.md).

For privacy documentation corrections, open an issue without including private documents or personal data. The current model is documented in [`PRIVACY.md`](PRIVACY.md).
